How to install
  1. Choose fonts, then Download .zip.
  2. Open the game folder: in Steam, right-click Counter-Strike 2 → Properties… → Installed Files → Browse…. It opens the folder Counter-Strike Global Offensive.
  3. Unpack the zip there and let it replace the files. It only holds a folder game: the fonts go to game\csgo\panorama\fonts, the rules to game\core\panorama\fonts\conf.d\99-spddl.conf.
  4. Restart CS2: it reads its fonts only at startup. Start CS2 via Steam

Undo: delete 99-spddl.conf (or unpack a zip downloaded without changes). The font files named notosans-… that the zip added can be deleted too; keep the game's own notosans-regular.ttf, notosans-bold.ttf and the other Noto files.

Steam's “Verify integrity of game files” leaves the added files alone.

Groups you do not change are shown in Stratum2 if it is installed on this PC, otherwise in a similar stand-in font (Saira). In the game they keep using Stratum2.

Preview ≠ game (Pango/FreeType, hintnone). Google fonts come from Fontsource; the zip holds Latin, Cyrillic, Greek and Vietnamese characters, other scripts use the game's own fonts.

No changes

No zip to unpack: the Windows desktop version applies the fonts to the game directly and restarts CS2.
